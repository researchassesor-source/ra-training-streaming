Configurar Facebook Live

Obtén estos datos desde Facebook Live Producer.

  1. Abre Facebook Live Producer.
  2. Selecciona “Software de streaming”.
  3. Copia Server URL y Stream Key.
  4. Pégalos en R.A. Training.
  5. Pulsa “Iniciar transmisión”.
  6. Cuando Facebook muestre la previsualización, vuelve allí y pulsa “Transmitir en vivo”.

Este flujo es manual: R.A. Training confirma el envío de señal, no que Facebook ya la haya publicado.
